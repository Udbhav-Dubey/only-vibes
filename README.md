# only-vibes

A home for random things I vibe coded.

There's no big reason behind any of it. I felt like building something, so I vibe coded it, and I needed a place to keep all that randomness. This repo is that place.

## What's inside

Each project lives in its own folder.

| Folder | What it is |
|--------|------------|
| [`music-server`](./music-server) | A frontend showdown: ChatGPT, Claude and Gemini each wrote a UI for my C++ HTTP server, [posix-server-nirvana](https://github.com/Udbhav-Dubey/posix-server-nirvana/) |
| [`graph-plotter`](./graph-plotter) | A small Python script that turns lab readings (CSV) into graphs, with best-fit lines and a terminal mode. Made by Claude alone, and one attempt was more than enough |

More will show up whenever the mood strikes.

## Disclaimer

Everything here is vibe coded unless stated otherwise. If I pull in something older that I wrote by hand, I'll link to where it came from. If there's no link, assume it was vibe coded. That includes this README.

## Rules

There are none. Some things here are half-finished, some are weird, and some might not even work anymore. That's the point.

## Why vibe code?

My serious work is systems programming. This repo is the opposite: no plan, no design doc, no deadline. I just build something and see what happens.
